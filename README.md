# Shayne Stark — CV

Open `index.html` in a modern browser. No install, build, server, or external assets required.

Files: `index.html` (content), `styles.css` (responsive design), `script.js` (current year), `assets/` (portrait and favicon).

## Content sources

- https://shaynestark.com/ — professional roles, skills, education, and interests; accessed October 23, 2026.
- https://tabl.page/ — TABL product context; accessed October 23, 2026.
- Existing TABL website profile material — CEO title and portrait.
- https://play.google.com/store/apps/details?id=page.tabl.impostergame — public professional email.
- https://www.linkedin.com/in/shaynestark/ — user-provided profile, linked throughout. LinkedIn blocked automated retrieval; its employment details could not be independently read.

Employment dates, degrees, performance metrics, and unverified past employers have intentionally been omitted. Roles reflect the existing public CV and should be reviewed for current accuracy before publishing. Contact buttons open a native modal dialog with a full-page backdrop, keyboard focus containment, Escape dismissal, and a close button. The contact form posts name, email, and message to https://formspree.io/f/mppppapa using native browser validation and Formspree’s hosted response page. No analytics, cookies, frameworks, or third-party runtime dependencies. Saved locally; not deployed.
